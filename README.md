# Discharging Rules
The directory `R` contains rule files in $\mathcal{R}$.
There are 35 rules in $\mathcal{R}$.
Considering all mirrors, there are 70 rules.
Thus, there are 70 rules in the `R` directory.

The directory `R_auxiliary` contains auxiliary files necessary to execute the cartwheel algorithm. See Section 6.3.4 in the paper.
